# Setting up for speedruns

All the information needed to set up the PC version of The Run for speedruns.

## Game version

To this day, two versions of the game exist : 1.01 and 1.1. Only the **1.1 version** of the game is available digitally nowadays and is the version used for the speedrun. If you don't have it, you can download the full game [here](https://mega.nz/folder/c4o2Tbbb#jXMHI3VqPF4GVYfJo6MxCw/folder/lsJmRDDZ) (Mega dump) or [here](https://drive.google.com/file/d/1Jg6EAEHbzUjpVPQScPYt_uPUG-vk8RVs/view?usp=drive_link) (Torrent file). <font color="grey"><u>Both are the same game, repacked by elAmigos.</u></font>

If you used the `Ultimate Unlocker` to unlock everything in the game, you might want to "downgrade" your game using [this patch](https://www.speedrun.com/static/resource/gdx73.zip?v=e2376cf). Back up your old `.exe` and `.par` files in case you need to revert to them.

> *Known issue : `Continue the Run` will always appear in the `Career` menu even if your save file has no progress. Don't select it with zero current career progress, otherwise your game will crash.*

**You can choose any language to run the game.** You don't get any advantage by choosing one specific language.

### Console ?

You can run The Run on console : PS3 or Xbox 360. However, you will have slightly longer load screens and the console accessibility is low. But if you really want to run on console, you will need to **set your hardware date before November 2011**.

## Validating your installation

### Limited Edition

This edition adds 3 additional cars and 5 Challenge Series events. No matter the edition you have ("Vanilla" or Limited), you can run the game freely as any of the additional cars aren't used throughout the run.

### Fusion fix (aka Widescreen fix)

To this day, the use of the Fusion fix hasn't been validated or rejected by the speedrun.com game rules. It might been revised but **I wouldn't use it** since it doesn't bring any widescreen support. *At your own risk.*

### Controller support

The game has full support for XInput (Xbox) and DualSense (PlayStation) controllers including buttons.

## Framerate requirements

**Locking the frame rate up to 30 FPS is required for speedruns.** You can use the ingame vsync option if you have a 60hz display. If not, I recommend [RivaTuner Statistics Server (RTSS)](https://www.guru3d.com/download/rtss-rivatuner-statistics-server-download/) or your graphics driver.

**Displaying your framerate is also required.** You can use [RivaTuner Statistics Server (RTSS)](https://www.guru3d.com/download/rtss-rivatuner-statistics-server-download/) for this too, or the overlay of your graphics driver. If you are using [OBS](https://obsproject.com/) and RTSS, enable Use Microsoft Detours API hooking in the settings of RTSS and enable Capture third-party overlays in the Game Capture of OBS. You can follow [this tutorial](https://www.youtube.com/watch?v=ppFk7agVOhU) for easier comfort.

## LiveSplit and timing

LiveSplit is a timer program for speedrunners that is both easy to use and full of features. You can download it [here](https://livesplit.org/downloads/).

**The primary timing method for this game is Load Removed Time (LRT)**, or LoadLess (LL). Loading times are not consistent in this game, depending on FPS, hardware configuration and loaded content.

**Please use LiveSplit with the load remover and auto-splitter activated in the Splits Editor**. By settting the Game Name to `Need for Speed: The Run`, the load remover + auto-splitter appears and you will be able to activate and modify it. Alternatively, you can add an .asl file and an .asi file that activate the load remover and the auto-splitter (check the [**Premade Subsplits section**](https://xicecreaam.github.io/nfsd-recreation/tr/setup/#premade-subsplits) below).

> :bangbang: The difference between both auto-splitters is that the Livesplit in-built one is only splitting **after events** whereas the .asl file does split **"everywhere"** (after events, after `Car select` sections, etc.).  
> :warning: *You will need to remove/add some splits depending on which method you will use.*

**Make sure Refresh Rate in LiveSplit Settings is set to 60 or higher**, otherwise the load remover and autosplitter might not work correctly.

You can follow [this tutorial](https://www.youtube.com/watch?v=aV5xdbrt5Qs) for more information.
