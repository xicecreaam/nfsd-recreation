# Setting up for speedruns

All the information needed to set up the PC version of ProStreet for speedruns.

## Game version

Two versions exist to run the game : **1.0** and **1.1**, but the fastest route is using **1.1**.

**You can choose any language to run the game.** You don't get any advantage by choosing one specific language. Languages without a dub will have voicelines in english but the text will be translated still.

### Console ?

You can run ProStreet on console : PS2, PS3, Xbox 360, Wii... However, you will have longer load screens and the console accessibility is low.

## Validating your installation

### 1.1 (aka Booster Pack DLC)

To know if you are using the correct version, you can look at the top right corner in the **splash screen** (the `CLICK to continue` screen). It would show either 1.0 or 1.1 (it can be difficult to see since it's a grey text on top of grey textures).

### Widescreen fix

**The only modification currently allowed is [an older version of widescreen fix](https://www.speedrun.com/nfsmw05/resources/wpwzz).** Why an older version ? Newer versions contain an setting called `SimRate` that modifies the physics of the game in general. To install widescreen fix, extract the contents of the archive into your game folder.

After you've installed the widescreen fix, enter the scripts folder and open `NFSProStreet.GenericFix.ini` with a text editor to configure it. **SkipIntro isn't allowed for speedruns** based on the rules of the game. You might want to disable the in-game motion blur by enabling the `DisableMotionBlur` setting.

### Controller support

#### Xbox (XInput)

The game has full support for XInput (Xbox) controllers including button overlays with `ImproveGamepadSupport = 1` in `NFSProStreet.GenericFix.ini`.

#### PlayStation

To display Playstation buttons ingame, set `ImproveGamepadSupport = 2` in `NFSProStreet.GenericFix.ini`. I didn't try the Steam method like explained [there](https://xicecreaam.github.io/nfsd-recreation/mw05/any/setup/#playstation) since I don't have a PS controller.

#### Deadzone

You can configure the deadzone in `NFSProStreet.GenericFix.ini` by changing `LeftStickDeadzone`. You can use [Gamepad Tester](https://hardwaretester.com/gamepad) to determine the minimum safe value. Best setting depends on your preference. If you want a sensitive stick, set it as low as you can without the car turning on its own, otherwise use slightly higher values. The default value of 10 works well enough for most.

## Framerate requirements

**Locking the frame rate up to 170 FPS is required for speedruns.** 120 FPS can be viable but the final time will be slower than if you were running in 170 FPS. You can use [RivaTuner Statistics Server (RTSS)](https://www.guru3d.com/download/rtss-rivatuner-statistics-server-download/) or your graphics driver to limit your FPS.

**Displaying your framerate is also required.** You can use [RivaTuner Statistics Server (RTSS)](https://www.guru3d.com/download/rtss-rivatuner-statistics-server-download/) for this too, or the overlay of your graphics driver. If you are using [OBS](https://obsproject.com/) and RTSS, enable Use Microsoft Detours API hooking in the settings of RTSS and enable Capture third-party overlays in the Game Capture of OBS. You can follow [this tutorial](https://www.youtube.com/watch?v=ppFk7agVOhU) for easier comfort.

## LiveSplit and timing

LiveSplit is a timer program for speedrunners that is both easy to use and full of features. You can download it [here](https://livesplit.org/downloads/).

**The primary timing method for this game is Load Removed Time (LRT)**, or LoadLess (LL). Loading times are not consistent in this game, depending on FPS, hardware configuration and loaded content.

**Please use LiveSplit with the load remover and auto-splitter activated in the Splits Editor**. By settting the Game Name to `Need for Speed: ProStreet`, the load remover + auto-splitter appears and you will be able to activate and modify it. Alternatively, you can add a .asl file that activate the load remover and the auto-splitter.

**Make sure Refresh Rate in LiveSplit Settings is set to 60 or higher**, otherwise the load remover and autosplitter might not work correctly.

You can follow [this tutorial](https://www.youtube.com/watch?v=aV5xdbrt5Qs) for more information.
